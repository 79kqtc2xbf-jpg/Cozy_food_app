## Следующий технический патч

### v34 — only if QA finds a real bug

Не делать v34 просто ради версии.

Возможные причины для v34:

- v33 ломает карточки;
- fallback картинок выглядит плохо технически;
- iPhone отдаёт старый кэш;
- какой-то подключённый JS-файл конфликтует;
- модалка / таймер / список покупок сломаны.

План v34, если понадобится:

1. Зафиксировать конкретный симптом.
2. Найти затронутый файл.
3. Сделать маленький патч поверх v33.
4. Поднять версию до `webstable34-[short-name]`.
5. Обновить `VERSION_LOG.md`.
6. Проверить GitHub Pages и iPhone Safari.

Только после технической стабильности:

1. Проверить первые 10–15 рецептов.
2. Убедиться, что картинки не ломаются.
3. Убедиться, что PWA не отдаёт старый кэш.
4. Подготовить showcase-ссылку.
5. Не делать генерацию изображений в этом Project без явной просьбы.
