# NEXT_STEPS.md

Ближайшие технические шаги Cozy Foodie после патча `webstable34-recipes-1000`.

## Срочно

### 1. QA v34 recipes 1000

URL:
`https://79kqtc2xbf-jpg.github.io/Cozy_food_app/?v=webstable34-recipes-1000`

Проверить:

1. Приложение открывается без белого экрана.
2. Счётчик рецептов показывает новую большую базу.
3. Открываются старые и новые рецепты.
4. Поиск работает по названию, ингредиентам и категориям.
5. Категории на главной фильтруют список.
6. «Чего хочется?» открывает подборки.
7. «Дома» ищет по ингредиентам.
8. Рандом открывает случайный рецепт.
9. Список покупок принимает ингредиенты из рецептов.
10. iPhone Safari не показывает старую версию из кэша.

### 2. Выборочная проверка качества базы

Проверить:

1. Первые 20 рецептов.
2. 20 рецептов из середины базы.
3. Последние 20 рецептов.
4. Нет духовки в шагах.
5. Нет сложных ингредиентов.
6. Шаги понятные и содержат время / огонь там, где нужна плита.
7. Категории остаются из разрешённого набора.
