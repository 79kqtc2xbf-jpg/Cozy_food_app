## Срочно

### 1. Проверить текущую stable-ссылку

URL:
`https://79kqtc2xbf-jpg.github.io/Cozy_food_app/?v=webstable18-manual-top-steps`

Проверить:

1. Приложение открывается.
2. Рецепты открываются.
3. Таймеры запускаются.
4. Звук таймера работает.
5. «Чего хочется?» работает.
6. «Дома» работает.

8. Нет белого экрана.

Проверить:

1. Какие CSS подключены.
2. Какие JS подключены.
3. Есть ли `v19-manual-more-steps.js`.
4. Нет ли конфликтующих старых версий.
5. Совпадает ли query version с подключениями.
