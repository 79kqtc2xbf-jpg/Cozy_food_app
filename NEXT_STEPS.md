## Следующий технический патч

### v37 — only if QA finds a real bug

Не делать v37 просто ради версии.

Возможные причины для v37:

- v36 ломает загрузку рецептов;
- очищенная база содержит заметную контентную ошибку;
- iPhone отдаёт старый кэш;
- какой-то подключённый JS-файл конфликтует;
- модалка / таймер / список покупок сломаны.

План v37, если понадобится:

1. Зафиксировать конкретный симптом.
2. Найти затронутый файл.
3. Сделать маленький патч поверх v36.
4. Поднять версию до `webstable37-[short-name]`.
5. Обновить `VERSION_LOG.md`.
6. Проверить GitHub Pages и iPhone Safari.
