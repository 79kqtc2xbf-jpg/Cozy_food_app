# QA_CHECKLIST.md

Чек-лист проверки Cozy Foodie после каждого технического патча.

## 1. Базовая web-проверка

1. Открыть GitHub Pages:
   `https://79kqtc2xbf-jpg.github.io/Cozy_food_app/`
2. Открыть версионную ссылку текущего патча.
3. Проверить, что нет белого экрана.
4. Проверить, что главный экран загрузился.
5. Проверить, что стили применились.
6. Проверить, что нет очевидного сломанного layout.
7. Сделать hard refresh.

## 2. Проверка основных сценариев

1. Открыть карточку рецепта.
2. Закрыть карточку рецепта.
3. Добавить рецепт в избранное.
4. Убрать рецепт из избранного.
5. Добавить ингредиенты в список покупок.
6. Открыть список покупок.
7. Отметить ингредиент купленным.
8. Очистить купленное.
9. Проверить кнопку «Выбери за меня» / рандом.
10. Проверить нижнее меню.

## 3. Проверка блоков главной

1. «Что едим?» отображается без дублей.
2. «Чего хочется?» отображается и нажимается.
3. «Дома» отображается и быстрые ингредиенты работают.
4. Поиск работает отдельно.
5. Плавающий рандом не мешает основному экрану.
6. Нет наложения кнопок на iPhone.

## 4. Проверка рецептов

1. Название рецепта отображается корректно.
2. Ингредиенты есть.
3. Шаги есть.
4. Шаги не пустые.
5. Граммовки отображаются.
6. Время приготовления отображается.
7. Уровень огня / плиты отображается там, где должен.
8. «Как готовить подробно» выглядит живым.
9. Финальная проверка готовности отображается.
10. Нет повторяющихся «Милых замечаний» в каждом шаге, если это уже исправлено.

## 5. Проверка таймеров

1. Таймер 1 минута запускается.
2. Таймер 3 минуты запускается.
3. Таймер 5 минут запускается.
4. Таймер 10 минут запускается.
5. Таймер 15 минут запускается.
6. Таймер 20 минут запускается.
7. Таймер по этапу запускается.
8. Таймер можно остановить / закрыть, если предусмотрено.
9. По окончании есть звуковое уведомление.
10. На телефоне проверить вибрацию, если браузер разрешает.

## 6. Проверка картинок

1. Картинки не чёрные.
2. Картинки не пропали.
3. Fallback отображается аккуратно.
4. Картинки не ломают layout.
5. Нет старого битого image URL в первых карточках.
6. Омлет не выглядит как паста.
7. Суп не выглядит как десерт.

## 7. iPhone Safari

1. Открыть сайт именно в Safari, не из иконки PWA.
2. Открыть версионную ссылку с query parameter.
3. Проверить нижнее меню.
4. Проверить открытие рецепта.
5. Проверить закрытие модалки.
6. Проверить избранное.
7. Проверить список покупок.
8. Проверить рандом.
9. Проверить таймеры.
10. Проверить, что старый service worker не отдаёт старую версию.

## 8. PWA / Home Screen

Проверять только после успешной Safari-проверки.

1. Удалить старую иконку с экрана домой, если была.
2. Открыть актуальную версию в Safari.
3. Добавить на экран домой заново.
4. Запустить из иконки.
5. Проверить, что версия не откатилась.
6. Проверить основные кнопки.

## 9. Перед показом другим людям

1. Открыть 10–15 разных рецептов.
2. Проверить первые экраны на iPhone.
3. Проверить, что нет очевидных технических багов.
4. Проверить, что GitHub Pages отдаёт актуальную версию.
5. Проверить, что README и VERSION_LOG обновлены.
6. Проверить, что текущие known issues зафиксированы.
